**Data:** 2026-01-12

## 1. Resumo Executivo

Esta pesquisa analisa as principais plataformas de delivery e e-commerce do mercado brasileiro e internacional, identificando funcionalidades de personalização que são consideradas **essenciais**, **importantes** e **diferenciais**.

## 4. Classificação de Funcionalidades

### 4.1 Essenciais (P0) - Sem isso, a loja parece incompleta

| Funcionalidade | Justificativa |
|----------------|---------------|
| **Horário de funcionamento** | Cliente precisa saber quando pode pedir |
| **WhatsApp/Telefone** | Principal canal de contato no Brasil |
| **Endereço** | Credibilidade e localização |
| **Pedido mínimo** | Viabilidade financeira do delivery |
| **Taxa de entrega** | Transparência de custos |

### 4.2 Importantes (P1) - Melhoram significativamente a experiência

| Funcionalidade | Justificativa |
|----------------|---------------|
| **Banner/Capa** | Impacto visual imediato |
| **Descrição da loja** | SEO e apresentação |
| **Redes sociais** | Engajamento e credibilidade |
| **Status aberto/fechado** | Evita frustração do cliente |
| **Tempo estimado** | Expectativa de entrega |
| **Meta tags SEO** | Posicionamento no Google |

### 4.3 Diferenciais (P2) - Destacam da concorrência

| Funcionalidade | Justificativa |
|----------------|---------------|
| **Cupons de desconto** | Conversão e retenção |
| **Programa de fidelidade** | Recompra e LTV |
| **Avaliações** | Social proof |
| **Áreas de entrega** | Operação profissional |
| **Múltiplos períodos/dia** | Flexibilidade |
| **Chatbot WhatsApp** | Automação de atendimento |

### 4.4 Avançados (P3) - Para o futuro

| Funcionalidade | Justificativa |
|----------------|---------------|
| **Disparo em massa WhatsApp** | Marketing ativo |
| **Push notifications** | Engajamento |
| **Taxa por distância** | Precisão de custos |
| **Mapa integrado** | UX premium |
| **Dark mode** | Preferência do usuário |
| **Schema.org** | SEO avançado |

## 5. Diferenciais Competitivos Potenciais

### 5.1 O que Order Web já tem de diferente

1. **Fontes personalizadas** - Maioria dos concorrentes não oferece
2. **Showcases/Vitrines** - Organização flexível de produtos
3. **Tema CSS completo** - Cores aplicadas em todos os componentes

### 5.2 Oportunidades de Diferenciação

| Diferencial | Descrição | Esforço |
|-------------|-----------|---------|
| **Onboarding guiado** | Wizard de configuração inicial | Médio |
| **Preview em tempo real** | Ver storefront enquanto edita | Baixo |
| **Templates de loja** | Configurações pré-definidas por segmento | Médio |
| **QR Code automático** | Gerar QR Code para cardápio de mesa | Baixo |
| **Modo catálogo** | Desabilitar pedidos, só exibir produtos | Baixo |
| **Múltiplos idiomas** | Suporte a EN/ES além de PT | Alto |
| **PWA** | Instalar como app no celular | Médio |
| **Notificações por email** | Confirmação de pedido automática | Baixo |

## 7. Conclusões e Recomendações

### 7.1 Prioridade Imediata (Sprint Atual)

Implementar as funcionalidades **P0 e P1** que são de baixo esforço técnico mas alto impacto:

1. Horário de funcionamento + status automático
2. Contato (WhatsApp, telefone, email)
3. Endereço
4. Banner/Capa
5. Redes sociais
6. Pedido mínimo e taxa de entrega
7. Meta tags SEO

### 7.2 Próxima Sprint

1. Cupons de desconto
2. Entrega grátis acima de X
3. Tempo estimado de entrega
4. Favicon personalizado

### 7.3 Roadmap Futuro

1. Programa de fidelidade
2. Avaliações de clientes
3. Áreas de entrega com geolocalização
4. Chatbot WhatsApp
5. PWA
